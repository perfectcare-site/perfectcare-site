퍼펙트케어 홈페이지 1차 버전

[Cloudflare에 올리는 방법]
1. 이 ZIP 파일을 다운로드합니다.
2. Cloudflare 대시보드에서 '새로운 것을 배송하세요' 또는 Workers & Pages의 배포 메뉴를 엽니다.
3. 'Drop a folder, or a zip' 영역에 ZIP 파일을 끌어다 놓습니다.
4. 프로젝트 이름은 perfectcare-site 정도로 입력합니다.
5. 배포 후 만들어진 *.pages.dev 주소를 열어 확인합니다.
6. 아직 기존 Wix 도메인의 DNS는 변경하지 마세요.
7. 임시 주소에서 디자인과 문구를 먼저 확인한 뒤 도메인을 연결합니다.

[현재 포함된 페이지]
- 메인
- 서비스
- 정기청소
- 사무실청소
- 화장실청소
- 에어컨 분해청소
- 양산 / 김해 / 부산 지역 페이지
- 작업사례 3개
- 회사소개
- 문의
- robots.txt
- sitemap.xml
- 404 페이지

[SEO 설정]
- 페이지별 고유 title / description
- canonical URL
- Open Graph
- LocalBusiness 구조화 데이터
- robots.txt
- sitemap.xml
- 모바일 반응형
- 이미지 WebP 최적화
- 실제 작업지역 + 업종 + 서비스 키워드 구조

[중요]
- 헤더 로고는 임시 텍스트 로고입니다. 실제 퍼펙트케어 원본 로고 파일을 주시면 교체하면 됩니다.
- 작업사례의 사진 자리는 실제 현장사진을 넣기 쉽게 비워두었습니다.
- canonical과 sitemap은 perfectcareclean.com 기준입니다.
- 도메인이 달라지면 전체 주소를 바꿔야 합니다.
